# NoodleAI Daylight Theme

This is a presentation-only update, built on the NoodleAI Data Viewer + Orientation version.

## Changes
- Bright light workspace with white panels and soft blue/green accents.
- Readable navigation, device status, buttons and prediction panel.
- Improved focus indicator for keyboard navigation.
- Original IMU charts, locked Data Viewer Y-axis ranges, optional quaternion plots, training/deployment and BLE logic unchanged.
- Original `style.css` retained; presentation overrides reside in `theme-daylight.css`.
- Browser cache busting included in `index.html`.

## Publish
Replace the contents of your deployed `web/` folder with this package and push to GitHub. The existing firmware binary and installer manifest are unchanged.
